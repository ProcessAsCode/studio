    About Algomation Studio

    Algomation Studio is a visual editor for BPMN, DMN and CMMN models bundled into a Unified Algorithmic Process Format (UAPF) archive.

    • Author processes in BPMN
    • Define decisions in DMN
    • Model cases in CMMN
    • Export all into a single .uapf file

    UAPF is intended as a machine-readable container that AI agents and runtimes can execute as part of an "algorithmated" enterprise.

    Learn more at: algomation.io
